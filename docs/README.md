# DevPilot documentation

- `DevPilot_開発仕様書_v1.0.docx`: product and implementation baseline
- `architecture/`: system boundaries and diagrams
- `adr/`: durable architecture decisions and M1 decision gates
- `api/`: generated OpenAPI and protocol notes (introduced after M0)
- `security/`: threat model and secure implementation notes
- `runbooks/`: setup, diagnostics, recovery, and uninstall procedures

The specification wins over implementation notes. When two specification sections conflict, apply the documented priority: MVP completion criteria, then API contract, then screen description.
